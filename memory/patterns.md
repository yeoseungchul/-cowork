# 학습된 패턴 — 세션 간 지식 축적

> 에이전트가 관찰한 반복 패턴과 효과적인 접근법.  
> 마지막 업데이트: 2026-10-03

---

## 요청 유형별 패턴

### 문서 작성
- **패턴**: 공문서 → 격식체, 사내 문서 → 실용적 형식
- **주의**: 회사명 반드시 완전 표기 `(주)서진항공` (괄호, 주 포함)
- **체크**: 작성 후 오타·글자깨짐 검수 필수
- **개선 이력**: 초기 설정 (2026-09-08)

### 여행 상품 기획
- **패턴**: 목적지 → 비자 조건 → 일정 → 가격 → 특이사항 순서
- **주의**: 무사증 가능 여부 별도 표시
- **개선 이력**: 초기 설정 (2026-09-08)

### 파트너 커뮤니케이션
- **패턴**: 중국 파트너와는 위챗 문자로 소통. 중국어 원문 번역 후 목적 분석, 회신용 중국어 문안 제공
- **주의**: 정부·기관 교류 건은 상대측 자료 수령이 선행. 한국 기관이 승인할 수 있는 문건 구조 필요
- **개선 이력**: 2026-10-03 산둥 방문단 건

---

## 효과적이었던 접근법

- 번역 → 목적 분석 → 선행 자료 목록 → 공식 문건 순서 (2026-10-03)
- 확정 안 된 사항은 [확인 필요]로 표시, 후보 기관을 임의 지정하지 않음

## 도메인 지식 메모

### 중국 무사증 (비자 없는 중국 방문)
- 전담 여행사로서 관련 최신 규정 파악 필요
- 변경이 잦으므로 요청 시 최신 정보 확인

### 메디컬투어
- 라이센스 보유 (외국인 환자 유치)
- 주로 중국인 환자 대상
- 한국 병원 파트너십 활용

### 인/아웃바운드 구분
- **인바운드**: 외국인(주로 중국인) → 한국
- **아웃바운드**: 한국인 → 해외 (중국 전문, 전 세계 취급)
