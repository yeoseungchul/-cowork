# 스킬: 여행 상품 기획 절차

## 목적
인/아웃바운드 여행 상품을 체계적으로 기획하고 문서화한다.

## 사전 조건
- 목적지 정보
- 여행 유형 (인바운드/아웃바운드/메디컬투어)
- 대상 고객군
- 출발일 범위
- 예산 범위 (선택)

## 절차

### 1단계: 상품 유형 분류
```
□ 아웃바운드 - 중국 (전담)
□ 아웃바운드 - 기타 (전 세계)
□ 인바운드 - 외국인 한국 방문
□ 메디컬투어 - 외국인 환자 유치
□ 무사증 패키지
```

### 2단계: 비자/입국 조건 확인
- 목적지 비자 요건 (한국인 기준)
- 무사증 적용 여부 및 조건
- 체류 기간 제한
- 특이사항 (건강 증명서, 보험 등)

> ⚠️ **중국 무사증**: 조건이 자주 변경됨. 요청 시 최신 규정 반드시 확인.

### 3단계: 일정 구성
```
[일정 표준 구조]
- 항공편: 항공사, 출발/도착 시간, 경유 여부
- 숙박: 호텔명, 등급, 위치
- 관광: 포함 관광지, 자유시간 배분
- 식사: 포함 식사 횟수
- 이동: 버스/기차/현지 교통
```

### 4단계: 포함/불포함 사항 명시
**포함:**
- 왕복 항공료
- 숙박 (X박)
- 식사 (조식 X회, 중식 X회, 석식 X회)
- 현지 교통
- 관광지 입장료 (명시된 곳)
- 가이드비

**불포함:**
- 개인 여행자보험
- 여권 발급비
- 기타 개인 경비
- 팁

### 5단계: 가격 책정
- 성인 기준가 (2인 기준)
- 1인 추가 요금
- 아동 요금 (만 X세 이하)
- 유류할증료 별도 표기
- 시즌 할증 여부

### 6단계: 특이사항 및 주의사항
- 최소 출발 인원
- 취소 환불 규정
- 여행 보험 안내
- 현지 특수 상황

### 메디컬투어 추가 단계
- 파트너 병원 정보
- 진료 과목 및 의료진
- 통역 서비스 안내
- 의료 기록 준비 체크리스트
- 사후 관리 방안

## 체크리스트

- [ ] 비자 조건 최신 정보 반영
- [ ] 항공편 스케줄 실제 운항 여부 확인
- [ ] 호텔 등급 및 위치 적합성
- [ ] 가격 계산 오류 없음
- [ ] 포함/불포함 사항 명확
- [ ] 취소 환불 규정 명시
- [ ] 회사명 및 연락처 정확
