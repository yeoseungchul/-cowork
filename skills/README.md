## 스킬 추가 기준

새 스킬은 다음 조건 중 하나를 만족할 때 생성한다:

1. **3단계 이상**의 절차가 필요한 작업
2. **반복될 가능성**이 높은 작업 유형
3. **도메인 지식**이 중요하게 작용한 경우
4. **실수를 피하기 위한** 체크리스트가 필요한 경우

## 스킬 파일 형식

```markdown
# [스킬 이름]

## 목적
이 스킬이 해결하는 문제

## 사전 조건
필요한 정보/도구

## 절차
1. 단계 1
2. 단계 2
...

## 체크리스트
- [ ] 항목 1
- [ ] 항목 2

## 개선 이력
- YYYY-MM-DD: 변경 내용
```
