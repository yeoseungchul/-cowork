# 스킬: 서진 스타일 문서 작성

## 목적
(주)서진항공 · (주)서진월드투어의 공식 문서를 오타·오류 없이 작성한다.

## 사전 조건
- 문서 유형 파악 (공문, 제안서, 계약서, 이메일, 내부 보고서 등)
- 수신자/대상 파악
- 문서 목적 명확화

## 절차

### 1단계: 문서 유형 결정
- 공문서 → 격식체 (존댓말 + 직함 사용)
- 이메일 → 간결하되 정중하게
- 내부 보고서 → 실용적 형식
- 계약서/협약서 → 법적 표현 주의

### 2단계: 헤더 구성
```
문서번호: 서진항공-YYYY-NNN (공문의 경우)
수신: [수신처]
발신: (주)서진항공 대표이사 [성명]
날짜: YYYY년 MM월 DD일
제목: [명확하고 간결한 제목]
```

### 3단계: 본문 작성
- 첫 문단: 목적/요지 (두괄식)
- 중간: 세부 내용
- 마지막: 요청사항 또는 마무리

### 4단계: 회사 정보 표기
정확한 표기 (복사해서 사용):
```
(주)서진항공
(주)서진월드투어
```
- 괄호 안의 "주"는 반드시 포함
- 앞뒤 공백 없음

### 5단계: 검수 체크리스트
- [ ] 오타 없음
- [ ] 글자 깨짐 없음 (특수문자, 한자, 괄호 확인)
- [ ] 회사명 정확 표기
- [ ] 날짜 형식 일치
- [ ] 수신자 이름/직함 정확
- [ ] 전화번호·이메일 정확
- [ ] 첨부 파일 언급 시 실제 첨부 확인

## 자주 쓰는 표현

### 공문 시작
- "귀사의 무궁한 발전을 기원합니다."
- "평소 당사에 보내주시는 관심에 감사드립니다."

### 요청 표현
- "아래와 같이 협조해 주시기 바랍니다."
- "검토 후 회신해 주시면 감사하겠습니다."

### 마무리
- "잘 부탁드립니다."
- "감사합니다."
