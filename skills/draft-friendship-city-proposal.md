# 우호협력 교류 제안서 작성

## 목적
외국(주로 중국) 지방정부·기관의 방한 교류 요청을 받았을 때, 한국 시(市)급 기관과 대학이 내부 보고·승인할 수 있는 문건으로 정리한다.

## 사전 조건
- 상대측 의향 문서와 자료가 먼저 확보되어야 한다 (제안서는 자료가 오기 전에 확정하지 않는다).
- 한국 측 섭외 대상(시, 대학)은 대표님 인맥으로 확정한다. 후보를 임의로 지정하지 않는다.

## 절차
1. 원문(중국어 등)을 번역하고 목적·요구사항·제약을 분리한다.
2. 상대측에 요청할 선행 자료 목록을 만들어 먼저 보낸다 (아래 체크리스트).
3. 자료 수령 후 한국 시정부용 제안서를 작성한다. 구성: 제안 배경, 목적, 상대측 소개, 단계적 협력 구조, 방문단 개요, 일정, 시 측 요청사항, 기대효과, 비용·운영 책임, 행정 절차, 향후 추진, 붙임.
4. 대학용은 유학생·학술 교류 중심으로 별도 작성한다.
5. 회사명(주)서진항공·(주)서진월드투어를 정확히 표기하고 오타·글자깨짐을 검수한다.

## 체크리스트
- [ ] 상대측 주체 기관명, 담당자, 연락처, 직인 찍힌 의향서
- [ ] 방문단 명단 및 여권 정보
- [ ] 구체적 협력 프로젝트 1건 초안
- [ ] 도시 소개 자료
- [ ] 희망 일정, 경비 부담 방식
- [ ] 출국 승인 여부
- [ ] 같은 기관 소속 인원 분리 편성 확인
- [ ] 기념 시점(예: 수교 35주년) 표현 사실 확인
- [ ] 입국·비자 최신 규정 확인
