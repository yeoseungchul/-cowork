# 스킬: 세션 종료 메모리 업데이트 프로토콜

## 목적
세션이 끝날 때 학습한 내용을 영구 메모리에 저장하여 다음 세션에서 더 나은 지원을 제공한다.

## 사전 조건
- 세션에서 완료한 작업 목록 파악
- 새로운 패턴이나 선호도 발견 여부 확인
- 재사용 가능한 절차 식별

## 절차

### 1단계: 세션 로그 작성
`sessions/YYYY-MM-DD.md` 파일 생성:

```markdown
# 세션 로그: YYYY-MM-DD

## 완료한 작업
- [작업1]
- [작업2]

## 주요 결정사항
- [결정1]

## 새로 파악한 정보
- [정보1]

## 다음 세션 이어받기
- [할일1]
```

### 2단계: 패턴 업데이트
`memory/patterns.md` 업데이트:
- 새로운 요청 패턴 추가
- 효과적이었던 접근법 기록
- 실수와 수정 방법 기록

### 3단계: 사용자 프로파일 정제
`memory/user-profile.md` 업데이트:
- 새로 파악한 선호도 반영
- 커뮤니케이션 스타일 보정
- 도메인 지식 수준 업데이트

### 4단계: 컨텍스트 업데이트
`memory/context.md` 업데이트:
- 완료된 작업 상태 변경 (→ ✅ 완료)
- 새로운 대기 중 작업 추가
- 다음 세션 확인사항 업데이트

### 5단계: 스킬 생성/정제 판단
다음 중 하나라도 해당되면 스킬 파일 생성/업데이트:
- [ ] 3단계 이상 절차가 필요한 새 작업 유형
- [ ] 기존 스킬에 개선점 발견
- [ ] 새로운 도메인 지식 획득

### 6단계: GROWTH.md 업데이트
```markdown
### YYYY-MM-DD — [세션 주제]

**완료한 작업:**
- [목록]

**신규 스킬:** X개
**기존 스킬 정제:** X개
**메모리 업데이트:** [항목]

**다음 세션 제안:**
- [제안]
```

### 7단계: Git 커밋 & 푸시
```bash
git add -A
git commit -m "session: YYYY-MM-DD [주요 작업 한 줄 요약]

- [변경사항1]
- [변경사항2]

Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>"
git push -u origin [브랜치명]
```
