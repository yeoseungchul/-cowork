# 서진 에이전트 코워크 환경

> (주)서진항공 · (주)서진월드투어 대표이사를 위한 **성장형 AI 에이전트** 환경.  
> [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) 폐쇄형 학습 루프 원칙 기반.

---

## 핵심 개념

이 저장소는 단순한 메모장이 아닙니다.  
**세션이 쌓일수록 에이전트가 더 똑똑해지는 구조**입니다.

```
세션 시작 → 메모리 로드 → 작업 → 스킬 저장 → 메모리 업데이트 → 커밋 → 다음 세션
    └─────────────────────── 폐쇄형 학습 루프 ──────────────────────────────┘
```

---

## 디렉토리 구조

| 경로 | 역할 |
|------|------|
| `CLAUDE.md` | 에이전트 두뇌 — 세션 루프, 운영 지침 |
| `SOUL.md` | 페르소나 & 가치관 |
| `GROWTH.md` | 자기 개선 로그 |
| `memory/` | 영구 메모리 (사용자 모델, 패턴, 컨텍스트) |
| `skills/` | 재사용 스킬 라이브러리 |
| `sessions/` | 세션별 작업 로그 |
| `tasks/` | 작업 추적 |
| `.claude/` | Claude Code 훅 & 설정 |

---

## 5가지 자기개선 메커니즘

1. **자율 스킬 생성** — 복잡한 작업 완료 후 `skills/`에 절차 저장
2. **지속적 스킬 정제** — 스킬 사용 중 발견한 개선점 즉시 반영
3. **패턴 인코딩** — `memory/patterns.md`에 반복 패턴 축적
4. **세션 검색·리콜** — `sessions/` 로그로 과거 작업 추적
5. **사용자 모델링** — `memory/user-profile.md` 지속 정제
